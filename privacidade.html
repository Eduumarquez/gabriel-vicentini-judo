Política de Privacidade

Última atualização: 25 de outubro de 2026

Esta política explica como este site trata dados pessoais, de acordo com a Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018, a "LGPD"). Resumo: este site não coleta dados pessoais seus.

1. Quem é o responsável

O site apresenta a trajetória do treinador de judô Gabriel Vicentini. Para qualquer assunto sobre privacidade, fale pelo Instagram @vicentinijudo.

2. O que o site não faz

  • Não tem formulários, cadastro, login ou área de pagamento.
  • Não usa cookies.
  • Não usa Google Analytics, pixels de redes sociais, mapas de calor nem qualquer outra ferramenta de rastreamento ou publicidade.
  • Não carrega fontes, scripts ou imagens de serviços de terceiros: tudo é servido pelo próprio site.

Por isso o site não exibe aviso de consentimento de cookies: não há nada para consentir.

3. Armazenamento local no seu navegador

Depois que você faz o "Rei" na entrada, o site guarda no armazenamento de sessão do seu navegador (sessionStorage) a marcação gv-rei = 1. Ela serve só para não mostrar a entrada de novo enquanto a aba estiver aberta. A marcação não identifica você, não é enviada a ninguém e é apagada quando você fecha a aba.

4. Hospedagem

O site é hospedado no GitHub Pages, serviço da GitHub, Inc., nos Estados Unidos. Como qualquer servidor, o GitHub pode registrar dados técnicos de acesso, como o endereço IP do visitante, para fins de segurança e funcionamento do serviço. Esse tratamento é feito pelo GitHub, conforme a Declaração de Privacidade do GitHub. O responsável pelo site não recebe nem acessa esses registros.

5. Links para outros sites

O site traz links para o Instagram e para as reportagens usadas como fonte. Ao clicar, você passa a seguir as regras de privacidade desses sites.

6. Seus direitos

A LGPD (art. 18) garante a você, entre outros, os direitos de confirmar se seus dados são tratados, acessá-los, corrigi-los e pedir a sua eliminação. Como este site não coleta dados pessoais, normalmente não haverá dados seus a fornecer, mas você pode fazer qualquer pedido pelo canal do item 1. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

7. Mudanças nesta política

Se o site passar a coletar dados (por exemplo, com um formulário de contato ou ferramenta de estatísticas), esta política será atualizada antes disso, e o consentimento será pedido quando a lei exigir.
