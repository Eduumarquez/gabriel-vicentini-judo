# Gabriel Vicentini · Judô (protótipo)

Protótipo de site para o treinador de judô Gabriel Vicentini (@vicentinijudo).
**Não é o site oficial** e está bloqueado para buscadores (`robots.txt` e `noindex`) até a aprovação do professor.

- Página única em HTML, CSS e JavaScript puros, sem dependências nem rastreamento.
- Fontes hospedadas no próprio repositório (SIL Open Font License 1.1, ver `fonts/LICENSE-*.txt`).
- Todos os fatos têm fonte listada no rodapé do site.
